## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
소통 채널: 카카오톡 단체방 (긴급 호출 시 전화)

응답 시간: 일상 메시지는 4시간 이내, 마감일 전후 또는 멘션(@) 호출 시 1시간 이내 회신

수면/휴식 시간: 23:00 ~ 09:00 사이에는 긴급 건 외 답장 강요 금지

## 회의 규칙 / Meeting rule — 요일·시간·불참 처리
정기 회의: 매주 화요일 20:00 (온라인 Zoom/Discord, 1시간 내외)

불참 처리: 최소 회의 6시간 전 사전 공지 필수, 무단 불참 2회 누적 시 팀 페널티(추가 자료조사/서기 담당 등) 부여

회의록: 매주 돌아가며 1명이 작성 후 노션/구글 독스에 당일 업로드

## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량
최소 작업량: 매주 정기 회의 전까지 1인당 최소 1개 단위 업무 완료 (예: 파트별 자료조사 2건, 기능 1개 구현, 초안 작성 등)

진척도 공유: 매주 일요일 저녁까지 개별 진행 상황(완료/진행중/블로커) 공유

## 갈등 처리 / Conflict rule — 의견이 갈릴 때
의견 대립 시:

감정이 아닌 프로젝트 목표·평가 기준에 부합하는 근거로 10분간 각자 주장 정리

팀원 간 다수결 투표 진행

2:2 등 동률일 경우 담당 파트 실무자의 의견을 우선 채택하거나 교수님/멘토에게 질의

## 마감 규칙 / Deadline rule
최종 제출 기준: 공식 마감일 24시간 전에 모든 개별 취합 및 통합 완료

중간 검토: 최종 마감 3일 전 1차 통합본 공유 및 상호 피드백(크로스 체킹)

## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
회의 언어: 한국어

기록 언어: 한국어 (단, 코드 주석, 기술 용어, Git 커밋 메시지는 영어 병기/영어 사용)

## AI 사용에 대한 팀 합의 / Team agreement on AI use
#AI에 맡길 영역 (보조):

  브레인스토밍 아이디어 발산 및 목차 구성

  문장 교정, 번역, 문법 검토

  코드 디버깅 및 단순 반복성 보일러플레이트 코드 생성

#팀원이 직접 진행할 영역 (핵심):

  최종 결론 도출, 핵심 논리 전개, 인사이트 분석
  
  생성된 결과물의 팩트체크 및 출처 검증 (할루시네이션 방지)
  
  최종 보고서/코드의 무비판적 '복사-붙여넣기' 절대 금지 (본인이 설명할 수 있어야 함)
